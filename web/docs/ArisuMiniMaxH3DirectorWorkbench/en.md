# MiniMax H3 Director Workbench

Add **MiniMax H3 Director Workbench** to plan a film and render its segments in order. Connect its `prompt`, `video_settings`, and `resources` outputs to the matching inputs on **MiniMax H3 Hybrid to Video**.

To use a single setting elsewhere, also connect `video_settings` to **MiniMax H3 Unpack Video Settings**. Its `length` output gives the selected segment's generation frame count before continuation trimming.

## Plan the Film

1. Open **Film Setup** (or **Set up the film** on an empty sequence) to write the **Film Requirements**. Use your own format, including Markdown, for the story, required events, exact words, or continuity instructions. Set the canvas size in megapixels and use the two sliders to choose a generation range within 5–15 seconds per segment. Enter an optional target in minutes, including fractional minutes, to guide the approximate length of the whole film.
2. Open **Asset Library** to add images, videos, or audio and give each asset a note. Mute an asset to keep it in the library and exclude it from planning. Drag an asset by its handle to reorder the library, or focus the handle and press the up or down arrow key. Each asset keeps its notes and segment bindings when moved. Select its thumbnail to edit the default crop or clip. For video, choose whether to include its soundtrack.
3. Choose **Plan the film**. The selected Workbench agent prepares the outline, continuity decisions, requirement coverage, and all segment prompts in one task. Agent setup is shared with Prompt Workbench. For both planning and segment refinement, the agent has up to 60 minutes after input preparation finishes.
4. Compare the submitted requirements with the coverage the Director identified, the segments that cover each item, and the estimated runtime. Apply the plan in one edit. To change the whole sequence, edit **Film Requirements** and choose **Replan the film**. Undo restores the previous plan. If a plan exceeds the agent budget, reduce the brief or the requested scope and try again.
5. A film-wide writing skill applies to all segments except those with a locked choice. Automatic selection records the skill and its reason for each segment.

A film can contain up to 128 segments and 256 library assets. The saved film document is limited to 1 MiB. Each structured agent result is limited to 256 KiB of UTF-8 text, including all prompts and planning fields. The bundled writing skills' 7000-character prompt limit applies separately to each segment, before JSON escaping. The with-ref 350–500-word target applies to each prompt's detailed description. The provider’s context and output limits can be lower.

If Director reports an outdated agent image, open **Agent settings**, select the named provider, and click **Update CLI** before planning or refining a segment.

## Review a Segment

The **Sequence** cards show each segment’s intent, timing, transition, asset count, and render status. Click a card to select the segment and open its editor, or use **+ Add** to write a segment manually. **Prompt** holds the finalized text and any rendered footage. **Direction** holds the intent, timing, transition, opening and closing states, and sequence order. **Assets & Skill** holds the bound assets and writing skill. Edits are saved as you work. Use the arrow keys to switch focused tabs; close the dialog, choose **Done**, or press Escape to return to the cards. The render controls act on the selected card. Library assets are available to the director during planning. Only the current segment’s bindings are sent to Hybrid. Select a bound thumbnail to override the crop or clip interval for that segment. Video bindings also have a segment soundtrack setting.

Prompt tags follow the segment’s input order. For example, `<Picture 1>` refers to the first numbered picture for the selected keyframe tag setting. A saved stable tag such as `<Picture:umbrella>` follows the asset with ID `umbrella` as bindings move. A draft that refers to a video preview uses the source video's library ID. If you mute, remove, or replace a source before applying a draft, **Review Draft** identifies the affected segment. Unmute or restore the submitted source to apply that draft, or generate a new one with the current library.

To revise one segment, select it and open **Revise Prompt**. Describe the change for that segment and choose **Refine current segment**. The Director reads the whole plan and uses this request for the selected segment only. For a continuation, it automatically requests tail images when the previous take can be verified, **context_latent** is connected to Motion Context Load Latent, and **vae** is connected to the video VAE loader. With no usable tail images it can work from the plan. The draft review shows which context it used. You can describe any sound you heard or want to change in the same request. The agent receives still images and text. Review the proposed replacement before applying it. Neighbor suggestions are advisory.

## Render and Resume

To use the render controls, connect one Motion Context Load Latent to Motion Context. Feed Hybrid’s conditioning and latent into Motion Context, then connect its conditioning and Hybrid’s latent to the sampler. Connect the sampled latent to Motion Context Save Latent and to both VAE decoders. Feed the decoded picture and sound through Motion Context Trim using the Motion Context `trim_frames` output. Connect both trimmed outputs to Create Video at 24 fps, then connect Create Video to **Save Video** or to **Save Video Segment**. If several savers follow Create Video, the first render stops and a **Video saver for renders** selector appears; choose one and render again.

The generation range applies to requested seconds. Set both sliders to the same value to request a fixed duration. The backend converts each request to frames at 24 fps and aligns it upward on the H3 grid. For example, 15 seconds produces 362 frames (about 15.08 seconds). The timeline uses the aligned frame counts. Hard cuts use all generated frames. A continuation uses the previous take’s Motion Context, then trims the overlap from the delivered picture and soundtrack.

Each take gets its own directory, which holds its video and its latent. With **Save Video**, or with a blank project on **Save Video Segment**, that is `arisu_director/<take id>/` under the ComfyUI output directory. With a project `P` on **Save Video Segment** it is `P/director/<take id>/`, beside the project's other videos, and the take is published with a record that **Assemble Video** can list. Director reads the project before the run, so type it on the saver or build it with **Path Builder**, string primitives, or **Concatenate Text**; a project computed by another node is refused. Changing the project affects later renders. Earlier takes stay where they were saved and remain usable.

**Render current segment** renders the selected segment. **Render remaining segments** works forward from the selection and checks completed takes before submitting another generation. Stopping lets the current render finish. A changed or missing predecessor must be rendered again before continuing from it. A card that shows **Latent removed** still has its footage: the video plays and can be assembled, and only a continuation from that segment needs a new render.

Save the workflow to keep the applied film, library, segment selection, and render records. Keep the corresponding rendered videos and latent files under the ComfyUI output directory to resume. Planning drafts and agent activity live in the open workflow. A normal ComfyUI Run emits the selected segment’s three finalized outputs. Use the Director render buttons to record takes for later segments.
